EverCam 字幕播放器（非官方）：教師使用說明
======================================

專案網址：https://github.com/kaoshou/evercam-subtitle-player

【第一次安裝播放器】

推薦方式：將下載的 ZIP 解壓縮，保持「安裝字幕播放器.cmd」、player
資料夾及 scripts 資料夾在一起。雙擊安裝工具，再選擇 EverCam 課程
資料夾。安裝視窗可以直接按 Ctrl+V 貼上完整路徑，也可以使用
「貼上路徑」或「瀏覽資料夾」。顯示綠色的「可以安裝」狀態後按
「開始安裝」，安裝工具會自動複製所需檔案。

請勿把「安裝字幕播放器.cmd」單獨放進課程資料夾。

若要手動安裝，只把 player 資料夾「裡面的內容」複製到與 media.mp4、
config.js 相同的位置：

   index.html
   subtitles-data.js
   更新字幕.cmd
   字幕使用說明.txt
   css 資料夾
   js 資料夾
   tools 資料夾

不要複製整個 player 資料夾，也不要複製 scripts 資料夾。

原本的 media.mp4、config.js、cover.jpg 及章節資料都不需修改。


【以後加入或更新字幕，只要三步驟】

1. 將字幕檔放進課程資料夾（與 media.mp4 同一層）。

2. 依照以下規則命名：

   media.語言代碼.srt
   media.語言代碼.vtt

   常用範例：

   media.zh-TW.srt    正體中文（臺灣）
   media.zh-Hant.srt  正體中文（不限定地區）
   media.zh-CN.srt    簡體中文
   media.zh-Hans.srt  簡體中文（不限定地區）
   media.en.vtt       英文
   media.ja.srt       日文
   media.ko.vtt       韓文
   media.es.srt       西班牙文
   media.fr.vtt       法文
   media.de.srt       德文
   media.vi.srt       越南文
   media.id.srt       印尼文
   media.th.vtt       泰文

   同一種語言只能保留一個字幕檔。例如不能同時放入
   media.en.srt 與 media.en.vtt。

   若只有正體中文字幕，也可命名為 media.srt 或 media.vtt。只要資料夾內
   沒有 media.zh-TW.srt 或 media.zh-TW.vtt，工具就會自動將其視為正體
   中文（zh-TW）。media.srt 與 media.vtt 不可同時存在。

3. 雙擊「更新字幕.cmd」。完成後會自動開啟新版課程播放器。


【重要說明】

- 支援 SRT、VTT 與多國語字幕。
- 如果有 media.zh-TW.srt／vtt，或只有 media.srt／vtt，播放器預設顯示正體中文字幕。
- 學生可以從影片控制列的「CC」按鈕切換語言或關閉字幕。
- 「CC → 字幕外觀」可調整字幕大小、顯示樣式與顯示位置。
- 瀏覽器及作業系統支援時，控制列會顯示子母畫面按鈕。
- 更新字幕檔後，請再次雙擊「更新字幕.cmd」。
- 字幕檔建議使用 UTF-8 編碼。
- 不需要安裝程式、不需要網路，也不需要修改 config.js。
